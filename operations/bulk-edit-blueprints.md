# Bulk Edit Blueprints

It is now possible to bulk edit blueprints. Please do a backup of the files before using.

<figure><img src="../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>

You can open the window through the main bar option `DBTools --> Bulk Edit Blueprints`

This opens a new window where you can select multiple blueprints and edit parameters of those blueprints.
