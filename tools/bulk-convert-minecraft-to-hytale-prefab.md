# Bulk Convert Minecraft To Hytale Prefab

To use this tool you have to set the source folder and target folder. All files ending with either .bp or .schem/ .litematic will be converted to Hytale's Prefab format.

To use the prefabs you have to put the in the following folder of your Hytale installation:

`Hytale\UserData\Saves\<World Name>\prefabs`

Hytale installation path is typically located in your AppData:

`C:\Users\<Username>\AppData\Roaming\Hytale`
