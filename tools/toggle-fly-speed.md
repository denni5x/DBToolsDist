# Toggle Fly Speed

This is a simple shortcut which lets you toggle between to fly speeds. You can still set the fly speed with Axiom's fly speed slider.

This key bind is not bound by default, so you have to set it in the menu first to use it.

{% hint style="info" %}
You can access your Minecraft key binds with: Minecraft Menu > Options > Controls > Key Binds
{% endhint %}

<figure><img src="../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>

Once you change the fly speed a small widget appears on the side of your screen.

<figure><img src="../.gitbook/assets/image (1) (1).png" alt=""><figcaption></figcaption></figure>

Once you toggled between the flight speeds you can simply set each speed separately - Axiom's speed slider also updates once you toggle between both.
